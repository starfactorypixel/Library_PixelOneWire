# PixelOneWire

Библиотека 1-Wire и датчиков температуры DS18x20 (DS18B20, DS18S20, DS1822) для STM32 HAL.
Без STL и динамической памяти.

| Файл | Назначение |
|---|---|
| `OneWireDriver.h` | Шина: сброс, чтение/запись, поиск устройств, Read/Match/Skip ROM, CRC8 |
| `OneWireTSensor.h` | Один датчик с известным ROM: конвертация, чтение, фильтр сбоев |
| `OneWireTSens.h` | Все датчики на шине: поиск, неблокирующий опрос, колбэк, min/avg/max |

Температура везде в сотых долях градуса: `2537` = 25.37 °C. Неверное значение — `NO_VALID_TEMP` (`INT16_MAX`).

## Требования

- Таймер с частотой 1 МГц (1 тик = 1 мкс), запущенный через `HAL_TIM_Base_Start` и не используемый больше никем.
- Внешний подтягивающий резистор на линии (обычно 4.7 кОм).
- Перед библиотекой должен быть подключён HAL (обычно `main.h`).

## Все датчики на шине, неблокирующий режим

```cpp
OneWireDriver bus(GPIOB, GPIO_PIN_9, &htim1);
OneWireTSens<16> sensors(bus);                 // второй аргумент — период опроса, мс (по умолчанию 2000)

// главный цикл
if(sensors.Processing(HAL_GetTick()))          // true — прочитаны все датчики
{
	for(uint8_t i = 0; i < sensors.Count(); ++i)
	{
		if(sensors[i].IsValid() == false) continue;
		temp[i] = sensors[i].GetTemp() / 100;
	}
}
```

Вместо проверки результата `Processing()` (или вместе с ней) можно зарегистрировать колбэк:

```cpp
sensors.RegReadyCallback([](const OneWireTSensor *sensor, uint8_t count)
{
	for(uint8_t i = 0; i < count; ++i)
	{
		if(sensor[i].IsValid() == false) continue;
		temp[i] = sensor[i].GetTemp() / 100;
	}
});
```

Колбэк вызывается каждый раз, когда прочитаны все датчики: в `Processing()` и в `ReadAll()`.

За один вызов `Processing()` выполняется не больше одной операции на шине: поиск одного устройства (~15 мс), чтение одного датчика (~12 мс) или запуск конвертации (~2 мс). Если датчики не найдены, поиск повторяется каждые 5 с. Принудительно перезапустить поиск — `Rescan()`.

## Все датчики на шине, блокирующий режим

```cpp
sensors.Search();
sensors.Convert();
HAL_Delay(OneWireTSensor::CONVERT_TIME);
sensors.ReadAll();
```

## Один датчик с известным ROM

```cpp
static const OneWireDriver::rom_t ROM_OUTSIDE = {{0x28, 0xFF, 0x64, 0x1E, 0x15, 0x21, 0x03, 0x8C}};
OneWireTSensor outside(bus, ROM_OUTSIDE);

outside.Convert();
HAL_Delay(OneWireTSensor::CONVERT_TIME);
if(outside.Read()) temp = outside.GetTemp();
```

Узнать ROM датчика: подключить его к шине одного и вызвать `bus.ReadRom(rom)`, либо найти через поиск.

## Фильтр сбоев

Три неудачных чтения подряд прощаются: датчик остаётся валидным и отдаёт последнее верное значение. После третьего он становится невалидным до первого удачного чтения.

Неудачным считается чтение, если:
- датчик не ответил;
- не сошлась CRC;
- все байты нулевые (линия прижата к земле);
- пришли 85 °C сразу после включения питания, то есть датчик перезагрузился и конвертации не было.

## Индексы датчиков

Порядок поиска определяется ROM-кодами, поэтому индексы стабильны, пока набор датчиков на шине не меняется. Если датчик убрать, следующие индексы сдвинутся. Индекс за пределами `Count()` безопасен: `sensors[i]` вернёт пустой датчик, у которого `IsValid() == false`. Для жёсткой привязки сверяйте `sensors[i].GetRom()` или используйте `OneWireTSensor` с известным ROM.
